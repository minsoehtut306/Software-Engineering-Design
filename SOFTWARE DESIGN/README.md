# Software Design

This folder contains the **software design documentation** for the system.

---

## Contents
- **SOFTWARE DESIGN.pdf** – the detailed design report outlining:
  - System architecture and components
  - Class and module responsibilities
  - Data flow and interaction diagrams
  - Design rationale and considerations

## Purpose
The design document defines the system’s structure and behaviour before implementation. It specifies **how the system should be built**, serving as a foundation for coding, testing, and future maintenance.
