# Functional Software Test Plan

This folder contains the **test plan** that verifies the system against requirements.

## Contents
- **FUNCTIONAL SOFTWARE TEST PLAN.pdf** – detailed testing document.
- **COMPX341_25A_Assignment_Two_Specifications.pdf** – the project brief for test planning.

## Purpose
The test plan defines how the implemented system will be verified. It covers:
- Test cases mapped to functional requirements
- Expected inputs and outputs
- Testing methodology
- Pass/fail criteria

## How to Use
1. Open **FUNCTIONAL SOFTWARE TEST PLAN.pdf**.
2. Review the outlined test cases before running the system.
3. Use the test plan to guide validation during implementation and debugging.
